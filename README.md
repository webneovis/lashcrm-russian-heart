# Lashcrm Russian Heart

=== ЛОКАЛІЗАЦІЯ ===

Весь інтерфейс системи повинен бути виключно російською мовою.

Перекласти всі елементи інтерфейсу:

- назви сторінок

- меню навігації

- кнопки

- форми

- таблиці

- повідомлення про помилки

- повідомлення про успішні операції

- діалогові вікна

- статуси записів

- підказки та плейсхолдери

Не використовувати англійські назви в інтерфейсі.

Приклади:

Dashboard → Главная

Clients → Клиенты

Services → Услуги

Appointments → Записи

Today → Сегодня

Finance → Финансы

Settings → Настройки

Create Client → Добавить клиента

Edit → Редактировать

Delete → Удалить

Save → Сохранить

Cancel → Отмена

Scheduled → Запланировано

Confirmed → Подтверждено

Completed → Выполнено

Cancelled → Отменено

Усі тексти інтерфейсу повинні бути російською мовою.
